# AI use statement

A large language model (ChatGPT) was used as an assistance tool during this project.

It supported:

- debugging and reviewing Python code;
- discussing alternative modelling and validation approaches;
- refining plotting and Leafmap ideas;
- improving repository structure and reproducibility documentation;
- reviewing wording and interpretation of results.

The project data processing, model training, validation, testing, and figure generation were executed through the repository code. Numerical results reported in the repository are taken from those executed outputs rather than generated by the AI system.

AI suggestions were treated as proposals to be checked against the code, data, course material, and resulting outputs. The student remains responsible for the submitted code, interpretation, and final report.
